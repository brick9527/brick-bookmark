# 隐私政策（Firefox 版）

**适用于**：BrickBookmark（书签管理器浏览器扩展，下称"本扩展"）
**发布日期**：2026 年 10 月 15 日
**当前版本**：v0.14.1.3

## 概述

本扩展是面向各类浏览器的书签管理工具，**默认在本地运行，基础功能不收集、不存储、不上传任何个人数据**。

仅在用户**主动启用服务器功能**时，才会将必要的账号信息与反馈内容发送至**由开发者运营的公共服务器**。除服务器功能外，本扩展不进行其他网络通信，不包含广告和追踪组件。

本政策所称"个人数据"指可直接或间接识别个人身份的任何信息。本扩展在安装及使用过程中的数据处理行为均在本政策中充分披露，不存在隐藏的数据处理行为。

本政策主要针对 Firefox 浏览器编制；本扩展同时支持其他主流浏览器，相关政策原则上一致适用。

## 1. 我们处理哪些数据

### 1.1 本地数据（仅存于用户设备，不离开浏览器）

| 数据类别 | 内容 | 存储位置 | 用途 |
|---|---|---|---|
| 书签数据 | 书签、文件夹及树结构 | 浏览器书签 API | 本扩展的核心数据，仅用于展示与管理 |
| 置顶状态 | 置顶书签 ID 集合 | 浏览器扩展存储（local） | 呈现置顶分区 |
| 标签数据 | 标签定义及书签-标签关联 | 浏览器扩展存储（local） | 标签管理与筛选 |
| 备注 | 用户为书签添加的备注文字 | 浏览器扩展存储（local） | 备注展示 |
| 访问统计 | 书签访问频次、最近访问时间 | 浏览器扩展存储（local） | 排序与检索 |
| 回收站数据 | 已删除书签的元数据 | 浏览器扩展存储（local） | 误删恢复、到期自动清空 |
| 设置偏好 | 主题、字号、语言、默认排序等 | 浏览器扩展存储（local） | 个性化界面 |
| 登录状态 | 服务器访问令牌（启用服务器功能后） | 浏览器扩展存储（local） | 保持登录状态，登出即删除 |

以上数据全部存储在用户浏览器本地，本扩展开发者**无法访问**，也不会被上传至任何服务器。

### 1.2 服务器功能数据（需用户主动启用）

| 数据类别 | 内容 | 传输去向 | 用途 |
|---|---|---|---|
| 账号信息 | 用户名、密码（传输时加密）、登录令牌、邮箱（注册时填写） | 开发者运营的服务器 | 注册 / 登录 / 身份验证 |
| 反馈内容 | 反馈类型、文字内容、提交时间 | 开发者运营的服务器 | 接收用户意见与问题报告 |

> 提示：请勿在反馈内容中包含个人敏感信息（如身份证号、银行账号、密码等）。

### 1.3 我们明确不收集

- 浏览历史、当前浏览的网页内容
- 姓名、电话、地址等个人身份信息（账号、邮箱信息除外，见 1.2）
- 位置信息、搜索记录
- **健康、财务、支付等高度敏感信息**（此类信息与扩展功能无关，本扩展在任何情况下均不收集）
- 任何广告标识符或行为画像数据
- **任何非用户本人的个人信息**（本扩展不收集、也不向外部共享他人信息）
- IP 地址：启用服务器功能后，服务器日志可能**短暂记录** IP 地址，**仅用于安全防护**（如异常登录检测），日志将定期清理；不使用服务器功能时不会产生此类记录。

## 2. 数据如何使用

- **本地数据**：仅用于在用户设备上呈现书签管理界面、实现管理功能，不用于任何其他目的。
- **服务器数据**：仅用于完成用户主动发起的身份验证与问题反馈，不用于数据分析、营销或画像。
- **网络请求**：以下请求可能与外部发生
  - 链接校验 / 标题刷新：向用户指定的目标网站发送请求以检测可用性或获取标题；
  - 服务器功能：向开发者运营的服务器发送认证或反馈请求；
  - 公告拉取：管理页加载时自动向服务器拉取产品公告（不含个人数据）。
- 本扩展暂未收集用户数据（也不涉及到数据**聚合、匿名化**相关处理）；如未来功能确需收集数据，将遵循本政策与适用法律，并同步更新本政策。

## 3. 数据存储与传输

- **本地存储**：使用浏览器扩展存储（local），数据仅存在于用户设备，卸载扩展即全部删除。
- **网络传输**：不在未经允许的情况下传输任何本地书签数据；网络传输采用 **HTTPS 等现代加密方法**，不使用不安全通道传输个人数据。
- **存储期限**：
  - 本地数据在用户主动清除或卸载前持续存在；
  - **账号数据**在账号注销后删除；
  - **反馈内容**将定期清理（匿名化或删除）。
- **服务器所在地与跨境传输**：服务器由开发者运营，部署于**中国香港地区**。启用服务器功能时，相关数据传输将跨境进行。跨境传输的数据限于账号信息、反馈内容及安全日志（见 1.2、1.3），传输全程使用 HTTPS 加密，开发者采取合理的安全保障措施（如加密存储、最小权限访问控制）保护上述数据。**启用服务器功能即视为用户同意上述传输与处理。**

## 4. 第三方共享

本扩展**不向任何第三方共享、出售、出租或披露用户数据**，亦不从事任何形式的数据经纪（data brokering）活动。扩展内不含任何广告 SDK、统计 SDK 或第三方追踪代码。

- **云服务提供商（受托处理者）**：服务器以云服务器形式托管，云服务提供商仅作为受托处理者按开发者指令提供基础设施服务，不共享、不出售、不使用用户数据，其处理行为受本政策约束。
- 可能发生数据传输的仅有两种情形，均非"共享"给第三方服务商：
  1. 用户与开发者运营的服务器交互（传输账号与反馈数据，由用户主动启用）；
  2. 用户主动对目标网站发起的链接检测请求（仅返回链接可用状态与标题）。

## 5. 数据安全

- 本地数据保存在浏览器隔离的扩展存储空间中，仅本扩展可读写；
- 登录令牌存储于本地扩展存储，登出或 401 鉴权失败时自动清除；
- 服务器数据采取加密存储与访问权限最小化控制，传输全程使用 HTTPS 加密；
- 本扩展**不会公开披露**任何用户的认证信息；如发生涉及认证信息的安全事件，将及时通知受影响用户。

## 6. 用户权利与控制

| 操作 | 方式 | 效果 |
|---|---|---|
| 访问与查看信息 | 本地数据可在扩展界面中直接查看（书签、标签、备注、设置等）；服务器数据可通过登录账号在服务器侧访问 | 用户可随时了解本扩展处理的数据 |
| 更正与复制 | 通过设置页修改账号信息；需复制或更正数据的，通过联系方式提出，**7 个工作日内**响应 | 保障个人信息更正权、复制权 |
| 撤回同意 | 在设置页关闭服务器功能并登出，即视为撤回同意，服务器端同步删除对应数据 | 撤回后立即停止传输与处理 |
| 删除我的服务器数据 | 设置页"删除我的服务器数据"（密码二次确认） | 删除服务器端全部个人数据，账号与登录态保留 |
| 修改用户信息 | 设置页修改用户名 / 邮箱 / 密码（至少一项） | 修改即时生效，改密码后需重新登录 |
| 注销账号 | 登录页提供账号注销入口，申请后 **7 个工作日内**完成账号与数据删除 | 账号数据在注销后删除 |
| 清除全部本地数据 | 卸载扩展 | 本地数据（含设置、标签、备注、登录状态）全部删除 |
| 重置配置 | 设置页"重置配置" | 恢复默认设置 |
| 清除访问统计 | 设置页"清除访问次数" | 删除访问频次数据 |
| 清空回收站 | 设置页"清空回收站" | 彻底删除回收站内书签 |
| 退出登录 | 设置页"登出" | 删除本地登录令牌 |

## 7. 政策变更

本政策将随功能演进**持续更新**（新增功能时同步修订），变更时同步更新本文档、版本号与生效日期，并在扩展版本更新日志中说明。

## 8. 未成年人保护

本扩展为效率工具，**不包含任何成人内容**。由于服务器功能会处理账号信息，**未满 14 周岁的用户请勿使用账号登录与反馈功能**；如监护人发现未成年人的相关信息被处理，可通过下方联系方式提出删除请求，我们将在 7 个工作日内响应。
