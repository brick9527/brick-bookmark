# 权限用途说明

**适用于**：BrickBookmark（书签管理器浏览器扩展，下称"本扩展"）
**对应隐私政策版本**：v0.14.1.3（2026 年 10 月 15 日）
**说明**：本文件为隐私政策附件，独立说明本扩展所申请的各项浏览器权限及其用途，与隐私政策正文配套使用。

## Chromium 系浏览器（Chrome / Edge）

| 权限 | 用途 |
|---|---|
| `bookmarks` | 读写用户书签，实现书签管理的核心功能 |
| `storage` | 在本地保存置顶、标签、备注、设置等扩展数据 |
| `sidePanel` | 提供侧边栏界面，不离开当前页面即可访问书签 |
| `tabs` | 打开用户点击的书签链接（前台 / 后台） |
| `favicon` | 在书签列表中显示网站图标 |
| `alarms` | 定时维护任务（如回收站到期自动清空） |
| 任意网站访问（host permissions） | 仅用于用户主动触发的链接校验与标题刷新，后台不会自动访问任何网站 |

本扩展仅申请实现上述功能所必需的权限，不申请任何超出功能需求的权限。
