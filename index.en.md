## Meet BrickBookmark in One Line

**BrickBookmark** is a bookmark manager that **works the moment you install it — no registration, no login required**. A sidebar gives you one-click access to your frequently used bookmarks, while the full management page handles folders, tags, batch organization, and "bookmark health maintenance". Optionally connect a self-hosted server to unlock account and feedback features. Supports Chrome / Edge and other Chromium-based browsers.

## Why BrickBookmark

Most bookmark tools on the market share one problem: **your bookmarks end up in someone else's cloud**. They either force you to create an account and host your data on their servers, put core features behind a paywall, or only solve the narrow case of "collapsing my open tabs". BrickBookmark takes a different path — **local-first, free and open source, treating your bookmarks as a long-term asset**.

| Dimension | BrickBookmark | Cloud bookmark tools (e.g. Raindrop) | Lightweight tools (OneTab / Toby) | Browser built-in |
|---|---|---|---|---|
| Data storage | **On your machine, zero upload by default** | Cloud, account required | Mostly local | Local |
| Paywall | **Free, open source, no subscription** | Subscription for premium features | Partly paid | Free |
| Dead-link check / duplicate merge / title refresh | **Built-in toolbox** | Rarely available | No | No |
| Accidental-delete protection | **Recycle bin, 24h recoverable** | Some have it | No | No |
| Encrypted backup | **`.bbmk` encrypted export** | Mostly plain export | No | No |
| Polish & accessibility | OKLCH design system, WCAG AA | Excellent | Plain | Basic |

### Highlight 1: Ready the moment you install — zero sign-up, zero distractions

It just works after installation: no registration, no login, no upload. Open the sidebar and your frequently used bookmarks are there in an instant — even offline. Bookmarks, tags, notes, and settings all live locally in your browser. No ads, no tracking, and no "create an account before you can see your own data" gimmicks.

### Highlight 2: A "health check" toolbox for your bookmark library

Like any asset, a bookmark library can "get sick": dead links, duplicate entries, stale titles. BrickBookmark ships with three built-in tools:

- **Link checker** — batch-detects dead links with real-time progress; you can stop it anytime
- **Duplicate finder** — normalizes URLs to spot duplicates and merges them in one click (along with tags and notes)
- **Title refresher** — batch-updates page titles and icons

This is maintenance capability that mainstream tools (Raindrop / Toby / OneTab, etc.) generally lack.

### Highlight 3: Undo for accidental deletions

Deleted bookmarks go to the **recycle bin** and can be restored anytime within 24 hours — or permanently removed. The regret of a bookmark vanishing the moment you delete it, as with the native manager, simply doesn't happen here.

### Highlight 4: Portable, encrypted backups

The `.bbmk` encrypted backup format lets you safely take your bookmark library out of the browser and restore it anytime; HTML export keeps cross-browser migration effortless — switch browsers without leaving your collection behind.

### Highlight 5: A restrained, considered experience

- OKLCH color system with dark / light modes that transition naturally
- WCAG 2.1 AA contrast, full keyboard navigation, and support for reduced-motion preferences
- Simplified Chinese / English bilingual UI, automatically following your browser language

## Features at a Glance

> Everything you'd expect from a complete bookmark manager:

- **Bookmarks** — list / grid / folder-tree views, global search with four sort rules, pinning, batch move / tag / delete, notes and tags
- **Folders** — tree navigation, multi-color markers, drag-and-drop sorting, recycle bin protection
- **Tags** — create / edit / delete with colors, tag merging, filter by tag
- **Tools** — import / export (cross-browser HTML and `.bbmk`), link checker, duplicate finder, title refresher
- **Settings** — theme, font size, default sorting, language, maintenance actions

## Security & Privacy

- **Local by default**: core features collect, store, or upload no personal data; no ads, analytics, or tracking components
- **Minimal permissions**: only the permissions strictly required (bookmarks, storage, side panel, tabs, favicon, alarms)
- **Optional server features**: account login and feedback require explicit opt-in, fully encrypted over HTTPS; nothing is transmitted unless you use them
- **Uninstall = erase**: all local data is deleted when the extension is removed
